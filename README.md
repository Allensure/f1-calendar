# f1-calendar
# F1 赛程日历（北京时间）

2026 赛季剩余分站的一级方程式赛程，已换算为北京时间。

## 订阅

日历应用中选择「通过网址添加订阅」，填入：

    https://allensure.github.io/f1-calendar/f1-2026.ics

- iPhone / iPad：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历
- macOS：日历 → 文件 → 新建日历订阅
- Google 日历：其他日历 → + → 通过网址添加

## 说明

- 每站含 FP1、FP2、FP3、排位赛、正赛，共 25 个场次
- 排位赛与正赛在开赛前 10 分钟提醒
- 时间已按各站官方时刻表换算为北京时间（UTC+8）
- 数据来源：Formula1.com 官方 timetable
